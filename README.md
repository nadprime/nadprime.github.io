# Personal Blog

This repository contains my **personal blog and learning notes**, built with **Jekyll** and hosted on **GitHub Pages**.

The goal of this blog is to **learn in public** — to document what I study, build, and understand over time, using simple and durable tools.

🌐 **Live site:** [https://nadprime.github.io](https://nadprime.github.io)

---

## ✨ About

This is a **static website** generated by Jekyll from Markdown files.

* No backend
* No database
* No JavaScript framework
* No build tools required locally

The site is automatically built and published by **GitHub Pages** whenever changes are pushed to the `main` branch.

---

## 🧱 Tech Stack

* **Jekyll** — static site generator
* **Markdown** — content format
* **GitHub Pages** — hosting & CI
* **Minima theme** — clean, accessible, dark-mode capable

This setup is intentionally minimal to ensure **long-term stability and low maintenance**.

## ✍️ Writing a Blog Post

All blog posts live in the `_posts/` directory.

### File naming format

```
YYYY-MM-DD-title.md
```

### Example

```md
---
title: "What I Learned Today"
date: 2025-01-15
categories: [learning]
---

Today I learned how GitHub Pages builds Jekyll sites.
```

Once committed to `main`, the post will be published automatically.
